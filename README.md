# 骑遇 RideChoice

骑行街景选择与图像标注实验平台，面向“你愿意多骑几分钟？”等骑行环境研究。管理人员可整理素材、设计并发布实验、查看回答和导出数据；志愿者可参与路线选择、街景选择或评分任务。

## 功能

- 志愿者与管理人员工作空间分开；公开部署时管理人员须输入研究者设置的口令。
- 路线选择实验与逐图标注实验分开组织。
- 标注支持单图文字选择、打分，以及双图或多图比较；比较题可选最佳、最差或最符合真实骑行的场景。
- 每位参与者随机抽题，保存题序和候选图片呈现顺序；作答逐题保存，中途可继续。
- 管理人员可以查看逐题回答、管理素材并导出 CSV。

## 在线部署（Render）

仓库根目录的 `render.yaml` 会创建一个 Python Web 服务，并将数据库和上传图片保存在持久化磁盘。请在 Render 中使用 **New → Blueprint** 连接本仓库，并在首次创建时填写 `RIDECHOICE_ADMIN_PASSWORD`。请设置至少 12 位、未在其他地方使用的口令，只交给研究管理人员。

服务采用新加坡区域。持久化磁盘和 Web 服务可能产生费用；创建前请检查 Render 显示的方案和费用。磁盘只挂载到单个服务实例，因此当前部署按单实例运行。Render 的持久化磁盘只保留挂载目录内的数据，项目已将 `RIDECHOICE_DATA` 指向 `/var/data`。

部署完成后，先访问 `/api/health` 确认返回 `"ok": true`，再测试志愿者登录、管理人员口令登录、创建/发布演示实验和 CSV 导出。不要将本机 `data/` 目录或含参与者信息的文件提交到公开仓库。

## 本机运行

需要 Windows 和 Python 3.10 或更新版本，无需安装额外 Python 依赖。

1. 下载或克隆本仓库。
2. 双击 `启动平台.bat`。
3. 浏览器打开 `http://127.0.0.1:8896/`，输入昵称并选择身份。
4. 双击 `停止平台.bat` 可停止服务。

本机版默认只接受本机访问；局域网参与需另行启动 `局域网参与.bat`。本机管理人员登录无需线上管理口令。

## 数据与研究伦理

在线部署后，参与者昵称、回答、实验数据库和研究者上传图片保存在托管服务的持久化磁盘中；请定期使用平台内的备份导出，并妥善保管备份和管理人员口令。`.gitignore` 已排除本机 `data/`、数据库、上传图片和日志。演示素材不代表研究数据。正式实验前请核验素材使用依据、知情同意文本、研究设计及数据管理方案。

## 源码

- `server.py`：HTTP 服务与 API
- `annotation.py`：街景题库、标注实验和作答数据
- `research_tools.py`：实验设计、素材管理与结果导出
- `web/`：页面、样式和演示素材
- `render.yaml`：Render 在线部署配置
- `使用说明.md`：详细操作说明
