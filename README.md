# 骑遇 RideChoice

骑行街景选择与图像标注实验平台，面向“你愿意多骑几分钟？”等骑行环境研究。研究者可整理街景素材、发布实验、查看作答并导出数据；志愿者可参与选择或评分任务。

## 功能

- 志愿者与管理人员分开登录；管理工作台仅开放给运行平台的本机。
- 路线选择实验和逐图标注实验分开组织。
- 标注支持单图文字选择、打分，以及双图或多图比较；比较题可选最佳、最差或最符合真实骑行的场景。
- 从题库为每位参与者随机抽题，保存题序和候选图片呈现顺序；中途可继续，完成后再次进入可重新抽题。
- 管理人员可以查看逐题回答并导出 CSV，比较题导出候选图片、呈现顺序和所选图片。
- 素材库支持批量导入、来源信息维护、筛选和归档。

## 本机运行

需要 Windows 和 Python 3.10 或更新版本，无需安装额外 Python 依赖。

1. 下载或克隆本仓库。
2. 双击 `启动平台.bat`。
3. 浏览器打开 `http://127.0.0.1:8896/`，输入昵称并选择志愿者或管理人员身份。
4. 双击 `停止平台.bat` 可停止本机服务。

也可在终端运行 `python server.py --port 8896 --open`。平台默认只接受本机访问；局域网参与需另行启动 `局域网参与.bat`。

## 数据与隐私

实验数据库、参与者昵称与回答、运行日志、以及研究者导入的原始图片保存在本机 `data/` 目录。该目录已加入 `.gitignore`，不会随本仓库提交。请勿将含参与记录或未经授权的研究影像添加到公开仓库。

内置演示图片仅用于体验，不代表研究数据；正式实验请核验素材来源、使用依据、研究设计和参与说明。平台不会自动判断回答正确性，也不代替伦理审查或统计分析。

## 说明

- 详细操作见 [使用说明](使用说明.md)。
- 平台服务由 `server.py` 提供，数据实验逻辑位于 `annotation.py`，研究设计与素材管理位于 `research_tools.py`。
- `web/` 包含前端页面、样式和内置演示素材。
